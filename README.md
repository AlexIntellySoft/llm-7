# DSL Query Generator: дообучение Qwen3-4B переводить русский язык в ECQL

Домашнее задание курса LLM. Малая модель (Qwen3-4B-Instruct-2507, 4-bit) дообучается
LoRA-адаптером переводить запросы на русском языке во внутренний язык запросов ECQL
вымышленной компании «E-Corp».

> Статус: датасет и код готовы, обучение в Colab ещё не запускалось. Результаты и отчёт
> появятся здесь после запуска.

## Структура

| путь | что там |
| --- | --- |
| `docs/teacher_prompt.md` | правила ECQL, схема и промпт модели-учителю |
| `tools/teacher_pairs.py` | 184 пары, сгенерированные учителем |
| `tools/build_dataset.py` | проверка пар парсером и разбиение 80/20 → `data/*.jsonl` |
| `data/train.jsonl`, `data/test.jsonl` | 148 / 36 примеров |
| `src/ecql.py` | грамматика ECQL: парсер, схема, нормализация |
| `src/evaluate.py` | метрики: синтаксис, логика, галлюцинации SQL |
| `src/finetune.py` | 4-bit загрузка, LoRA (PEFT), SFTTrainer (trl), генерация |
| `notebooks/train_colab.ipynb` | запуск обучения и оценки в Google Colab (T4) |
| `tools/smoke_test.py` | прогон всего пайплайна на крошечной модели на CPU |
