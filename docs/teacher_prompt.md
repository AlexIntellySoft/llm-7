# Промпт модели-учителю

Датасет сгенерирован моделью-учителем **Claude**. Ключ YandexGPT, которым пользовались
в прошлых заданиях, к этому моменту истёк. Учителю дали правила ниже и попросили пары
«запрос на русском — ECQL» от простых до вложенных. Каждый эталон затем автоматически
проверен парсером `src/ecql.py`: грамматика, поля сущности, типы значений, отсутствие SQL
(`python -m tools.build_dataset`). Результат — `tools/teacher_pairs.py`.

---

Ты генерируешь обучающие данные для перевода запросов с русского языка на корпоративный
язык запросов ECQL компании «E-Corp».

**Правила ECQL**
- Запрос всегда начинается с `FETCH`.
- Сущность пишется заглавными буквами в квадратных скобках: `[EMPLOYEES]`, `[PROJECTS]`,
  `[INVENTORY]`, `[DEALS]`.
- Условия идут после `WHERE`. Поле — с префиксом `@`, затем оператор и значение.
- Операторы: `IS` (равно), `NOT` (не равно), `ABOVE` (больше), `BELOW` (меньше).
  Для «не меньше/не больше» оператора нет — такие формулировки не используй.
- Связки: `&&` (И), `||` (ИЛИ). При смешении `&&` и `||` всегда ставь скобки.
- Строки — в одинарных кавычках, на английском; числа — без кавычек, полностью
  («150 тыс.» → `150000`, «2,5 млн» → `2500000`).
- В конце можно указать формат: `AS JSON`, `AS TABLE`, `AS LIST`. Только если пользователь
  явно его просит («в JSON», «таблицей», «списком»).
- Условия записывай в том порядке, в котором они упомянуты в запросе.

**Схема**

| сущность | поля |
| --- | --- |
| `[EMPLOYEES]` | `@name`, `@city`, `@department`, `@position`, `@status`, `@salary`, `@age`, `@experience` (лет) |
| `[PROJECTS]` | `@name`, `@status`, `@priority`, `@manager`, `@client`, `@budget`, `@team_size`, `@year` |
| `[INVENTORY]` | `@item`, `@category`, `@warehouse`, `@status`, `@quantity`, `@price` |
| `[DEALS]` | `@client`, `@stage`, `@region`, `@manager`, `@amount`, `@probability` (%), `@year` |

**Значения**
- города и склады: `Moscow`, `Saint Petersburg`, `Kazan`, `Novosibirsk`, `Yekaterinburg`, `Samara`, `Sochi`
- отделы: `IT`, `Sales`, `HR`, `Marketing`, `Finance`, `Legal`, `Support`
- должности: `Developer`, `Manager`, `Analyst`, `Designer`, `Accountant`, `Engineer`
- статус сотрудника: `active`, `on_leave`, `fired`
- статус проекта: `active`, `completed`, `on_hold`, `cancelled`; приоритет: `high`, `medium`, `low`
- категории товаров: `laptops`, `monitors`, `servers`, `phones`, `furniture`, `office_supplies`;
  статус товара: `in_stock`, `out_of_stock`, `reserved`
- этап сделки: `new`, `negotiation`, `won`, `lost`;
  регионы: `Central`, `North-West`, `Volga`, `Siberia`, `Ural`, `South`
- фамилии и названия — транслитерацией: Иванов → `Ivanov`, «Сигма Банк» → `Sigma Bank`

Сгенерируй ~180 пар по всем четырём сущностям: запросы без условий, с одним условием,
с несколькими условиями через `&&`, через `||` и вложенные со скобками. Формулировки
должны быть разнообразными: повелительные («покажи», «выгрузи»), вопросы («кто…?»,
«какие…?»), разговорные («ребята из саппорта»), числа словами и сокращениями.
